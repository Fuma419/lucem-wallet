# Vercel Deployment

**Trigger:** Agent modifies build config, `vercel.json`, or needs to deploy.

## Config
- `vercel.json`: `buildCommand: "npm run build:webpack"`, `outputDirectory: "build/"`, SPA rewrites.
- `package.json` `engines.node: "24.x"` — Vercel build/runtime (Node 20 is disabled after 2026-10-01).
- Secrets auto-generated by `utils/build.js` from `secrets.testing.js`.
- Token: `$VERCEL_TOKEN`, scope: `my-team-5c660a1c`, project: `lucem-wallet`.

## Which git refs deploy

`ignoreCommand` **builds** when:
- `VERCEL_ENV=production` (Production domain, usually `main`), or
- `VERCEL_GIT_COMMIT_REF=staging` (Preview / staging URL).

All other Previews (PRs, `agent/*` branches) are **skipped**. Do not remove that skip to “see every PR on Vercel.”

**Staging** is a hosting environment (separate origin / IndexedDB). It is not Cardano Preview or Preprod — those stay in-app network switches.

## Commands
```bash
vercel deploy --prod --token $VERCEL_TOKEN --scope my-team-5c660a1c --yes
```

## Rules
1. New HTML entry points → add rewrite in `vercel.json`.
2. New React Router routes → add rewrite.
3. Never add `build/` to git.
